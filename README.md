# Dependency Graph Visualizer

Инструмент визуализации графа зависимостей для менеджера пакетов Maven.

## Этап 1: Минимальный прототип с конфигурацией

CLI-приложение с настраиваемой JSON-конфигурацией:
- Имя анализируемого пакета
- URL репозитория Maven
- Режим тестирования с локальным файлом
- Имя выходного файла с графом
- Максимальная глубина анализа зависимостей

## Этап 2: Сбор данных

Реализовано получение прямых зависимостей из Maven-репозитория:
- Парсинг maven-metadata.xml для получения последней версии
- Парсинг pom.xml для извлечения зависимостей
- Вывод списка прямых зависимостей на экран

## Этап 3: Основные операции

Построение графа зависимостей с учётом транзитивности:
- Алгоритм DFS без рекурсии (явный стек)
- Ограничение по максимальной глубине
- Корректная обработка циклических зависимостей
- Режим тестирования с локальным файлом
- Пакеты в тестовом режиме — большие латинские буквы

### Примеры тестовых графов

В папке `test_graphs/` находятся примеры:
- `simple.txt` — простой граф без циклов
- `with_cycle.txt` — граф с циклической зависимостью
- `deep.txt` — глубокий граф для проверки ограничения глубины
- `no_deps.txt` — пакет без зависимостей
