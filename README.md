# Dependency Graph Visualizer

Инструмент визуализации графа зависимостей для менеджера пакетов Maven.

## Этап 1: Минимальный прототип с конфигурацией

CLI-приложение с настраиваемой JSON-конфигурацией:
- Имя анализируемого пакета
- URL репозитория Maven
- Режим тестирования с локальным файлом
- Имя выходного файла с графом
- Максимальная глубина анализа зависимостей

## Запуск

Через командную строку:
```bash
python -m src.main config.json
